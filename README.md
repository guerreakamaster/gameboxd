# Gameboxd

A game-logging web app — a Letterboxd for video games — where registered
users rate and review the games they've played and keep a personal log of
them, while admin users maintain the shared game catalogue.

## Stack

- **PHP 8.2.12** — server-side rendering and JSON endpoints
- **MariaDB / MySQL** — developed against MariaDB 11.5
- **Vanilla JavaScript** — `fetch` for data, no framework
- **HTML / CSS** — hand-written, CSS custom properties, no CSS framework
- **SweetAlert2** (CDN) — the only external dependency
- Local environment: **XAMPP** (Apache + MariaDB) on Windows
